# Images

Drop real images here using the exact file names listed in `src/content/media.js`.
They appear on the site automatically; until then a designed placeholder shows.

- Prefer `.webp`, roughly 1600px on the long edge (portraits 1200×1500).
- Ratios: portrait 4:5 · covers 16:10 · slides/screenshots 16:9 · photos 4:3 · certificates √2 landscape · logos square.
- Only your own photographs, certificates, screenshots and slides. No stock images.
- Cars24 visuals: anonymised or approved only. No internal data.
